# TaskMate — Student To-Do List Manager

A responsive student task management mini-project built with HTML, CSS, and vanilla JavaScript. Tasks are saved in your browser using `localStorage`.

## Features

- Create, edit, and delete tasks
- Task descriptions, subject categories, priorities, and due dates
- Mark tasks complete or pending
- Search tasks and filter by status or subject
- Sort by due date, priority, or recently added
- Dashboard statistics and completion progress
- Responsive desktop and mobile layout
- Browser-based persistence with localStorage

## Files

- `index.html` — page structure and task form
- `style.css` — responsive styling
- `script.js` — task logic and localStorage persistence

## Run locally

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser. You can also use the Live Server extension in VS Code.

No build tools or server are required.

## Publish with GitHub Pages

1. Create a GitHub repository named `taskmate-student-todo-list`.
2. Upload `index.html`, `style.css`, `script.js`, and this README.
3. Open **Settings → Pages** in the repository.
4. Under the build/deployment section, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. Wait for GitHub Pages to publish the site; the URL will appear on the Pages settings screen.

## Project abstract

TaskMate is a browser-based to-do list management application designed to help students organize coursework and daily responsibilities. Users can create tasks with categories, priorities, and due dates, track completion, and quickly search or filter their list. The application uses localStorage so tasks remain available in the same browser after refresh.

## Objectives

- Practice HTML page structure, CSS layout, and JavaScript DOM manipulation.
- Implement CRUD operations for tasks.
- Learn event handling, filtering, sorting, and form validation.
- Persist data with browser localStorage.
- Build a responsive user interface.

## Future enhancements

- User accounts and cloud synchronization
- Calendar view and reminder notifications
- Recurring tasks
- Export tasks to CSV
- Backend API and database integration

## Note

This is a learning project. The current version stores data only in the current browser and does not sync between devices.
